# Security

SashaExplorer runs with the rights of the user who starts it. It keeps its
state encrypted with Windows DPAPI for that user, and its only network request
is the optional update check on GitHub.

If you find a security problem, please report it privately through
[GitHub security advisories](https://github.com/yanbess/SashaExplorer/security/advisories/new)
rather than in a public issue. You will get an answer within a week.
