## [0.1.0] - 2026-11-13

The first public release of the file manager for fans of Cyberpunk: Edgerunners.

### Added

- Tabs with pins, two panes side by side, and tabs dragged between them.
- Details, icons, and gallery views, kept per folder, with sorting and folder
  sizes.
- A preview panel for pictures, videos, audio, text, and media details.
- Search in subfolders, a filter, and an address bar that takes typed paths.
- Copy, move, delete, and the Recycle Bin through Windows, with undo and redo.
- Dragging items to and from other programs.
- Settings in a window of their own: light, dark, or system theme; remembering
  the window's size, position, and maximized state; hidden files; Explorer
  integration; and saved thumbnails.
- A terminal button with every terminal found on the computer, a default
  terminal, and terminals added by hand.
- A daily check for new releases on GitHub, which can be turned off.
- A folder already open in a tab is shown there instead of opening twice.
- The Recent list folds to the bottom of the sidebar, as in VS Code, and its
  top edge changes its height. Splitters go back to their first size on a
  double click.
- Any terminal can be deleted from the list, after a question.
